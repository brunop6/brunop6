# Bruno Peres

Engenheiro de Computação pela UNIFEI, gosto de dados quando eles mudam uma decisão. Desenvolvo código de APIs, sistemas, modelagem e análise de dados de ponta a ponta.

**O que você encontra por aqui**

- **Produtos web e mobile** do app nas lojas ao painel de administrativo.
- **Dados em Python:** biblioteca open source de hidrologia e análises com segmentação e classificação.
- **Backend e SQL:** APIs REST, modelagem relacional, procedures e triggers, em PostgreSQL, MySQL e SQL Server.
